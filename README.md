# PrdctAI
Do humans create predictable ‘random’ behavior, and can a simple algorithm exploit it?

## What this repo shows
Yes. `prdctai.py` contains a tiny transition-based predictor that learns from prior choices and predicts the next one.

It targets a common human tendency when trying to be random: switching too often.

## Run the demo
```bash
python prdctai.py
```

## Run tests
```bash
python -m unittest -v
```
